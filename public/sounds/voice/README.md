# 키오스크 음성 안내 녹음 파일

이 폴더에 아래 이름의 `.mp3` 파일을 넣으면 키오스크가 그 목소리로 안내합니다.
라즈베리파이 Chromium에는 한국어 음성(TTS)이 없어서, 이 파일이 없으면 음성 안내 없이 효과음만 납니다
(한국어 음성이 있는 기기·브라우저에서는 그 음성으로 대신 읽습니다).

- 문장 하나에 필요한 파일이 **모두** 있을 때만 녹음 파일로 재생합니다. 하나라도 빠지면 그 문장은 기기 음성으로 읽거나 넘어갑니다.
- 주문 완료 안내는 `done` + 숫자 파일(`num-*`) + `done-tail`을 이어서 재생합니다. 예: 주문번호 37 → `done`, `num-3`, `num-10`, `num-7`, `done-tail`.
  숫자 파일은 이어 붙였을 때 자연스럽도록 앞뒤 무음을 짧게(0.05초 이하) 잘라 주세요.
- 파일을 바꾼 뒤에는 키오스크 화면을 새로 고치면(관리자 모드 › 전원 › 새로고침) 다시 받습니다.
- 성우 녹음이나 TTS 서비스로 만들 수 있습니다. 상업적 이용이 허용된 음성인지 확인해 주세요.
- 문장을 바꾸려면 `lib/kiosk-sound.ts`의 `VOICE_CLIPS`와 이 표를 함께 고쳐 주세요 (테스트가 둘이 같은지 확인합니다).

| 파일 | 내용 | 언제 |
| --- | --- | --- |
| `welcome.mp3` | 어서 오세요. 원하시는 메뉴를 골라 주세요. | 대기 화면을 눌러 주문을 시작할 때 |
| `review.mp3` | 주문 내역을 확인해 주세요. | 주문 확인 화면 |
| `identify.mp3` | 학번이나 아이디를 입력해 주세요. 선생님은 이름으로 찾을 수 있어요. | 본인 확인 화면 |
| `pin.mp3` | 키오스크 결제 비밀번호 여섯 자리를 눌러 주세요. | 결제 비밀번호 화면 |
| `pin-setup.mp3` | 처음 오셨네요. 결제할 때 쓸 비밀번호 여섯 자리를 정해 주세요. | 결제 비밀번호 만들기 화면 |
| `pin-confirm.mp3` | 확인을 위해 같은 숫자를 한 번 더 눌러 주세요. | 비밀번호 만들기에서 처음 6자리를 누른 뒤 |
| `pin-wrong.mp3` | 비밀번호가 맞지 않아요. 다시 눌러 주세요. | 결제 비밀번호가 틀렸을 때 |
| `done.mp3` | 주문이 완료됐어요. 주문번호 | 주문 완료 (앞부분) |
| `done-tail.mp3` | 번입니다. 음료가 준비되면 불러 드릴게요. | 주문 완료 (뒷부분) |
| `error.mp3` | 결제하지 못했어요. 화면의 안내를 확인해 주세요. | 결제 오류 화면 |
